## 二、本政策适用范围

本政策适用于 SecAgent 桌面客户端及其随客户端提供的本地会话、官方账号登录、官方模型、官方语音识别、朗读、更新和插件市场功能。

SecAgent 是一个具有本地处理能力、同时也可以连接网络服务的桌面应用。使用官方模型、官方语音识别、朗读、更新、插件、MCP 或用户自行配置的模型供应商时，相关数据可能离开本机并由相应服务处理。第三方服务的处理规则以其公开的隐私政策、服务条款或用户与其订立的协议为准。

## 三、我们处理哪些信息

### 1. 本地工作区和应用配置

SecAgent 默认在以下位置创建工作区：

```text
~/SecAgentWorkspace
```

用户也可以通过 `SECTL_WORKSPACE` 环境变量指定其他位置。根据用户使用的功能，本地工作区可能包含：

- `secagent.yaml`、`.env` 等应用和模型配置；
- 会话标题、会话消息、模型回复、图片附件和会话时间；
- 模型请求记录、工具调用参数及结果、运行事件和审计记录；
- 插件安装状态、插件配置、插件数据和导出文件；
- 应用错误日志、更新下载文件和安装记录；
- 用户主动配置的 API Key、官方服务访问令牌、账号邮箱和用户 ID。

上述内容由客户端写入用户指定的本地工作区。当前版本不宣称对本地配置文件、会话文件或日志文件进行静态加密。请妥善保护操作系统账户和工作区目录，不要将包含令牌、API Key、会话或学生数据的工作区提交到公共代码仓库或分享给他人。

### 2. SECTL 官方账号和官方服务

- 账号邮箱、用户 ID、账号显示信息；
- OAuth 授权码、设备标识符和访问令牌；
- 模型列表、账户余额和服务调用状态；
- 为提供模型服务而提交的用户消息、最近会话历史、系统提示词、图片附件、工具调用信息以及生成的回复；
- 为排查服务故障而产生的请求时间、错误信息和服务日志。

客户端将官方访问令牌、账号邮箱和用户 ID 写入本地工作区的 `.env` 文件。客户端代码不会将登录密码写入该本地配置文件；登录密码如被使用，会在登录操作中提交给相应的认证接口。认证服务端是否保存登录凭据以及保存多久，以认证服务的政策为准。

### 3. 会话、消息和图片

当用户发送消息或图片时，客户端会在本地保存用户输入、会话历史、图片附件和模型回复。为生成回复，客户端可能将当前消息、最近会话历史、图片附件、相关 Skill 内容以及工具调用上下文发送给当前选择的模型服务。

用户应确保其发送的内容具有合法来源和必要授权。特别是学生姓名、学生 ID、成绩、积分、联系方式、健康信息、未成年人信息、工作秘密和商业秘密，不应在没有合法依据或必要授权的情况下输入或上传。

### 4. 麦克风和语音功能

使用语音功能需要操作系统的麦克风权限。

- **随时唤醒：** 开启后，客户端会持续读取麦克风音频，并使用随应用提供的本地唤醒词模型进行处理。当前实现中，持续唤醒音频用于本地关键词检测，不以持续上传音频为目的。
- **唤醒后的语音识别：** 如果已登录官方服务，语音采样数据可能通过官方 ASR WebSocket 服务实时传输，用于转换为文字；如果没有可用的官方服务连接，客户端可能使用本地语音识别程序和本地模型处理。
- **朗读：** 使用朗读功能时，回复文本会被切分为语音片段并发送给当前使用的 Edge TTS 相关语音合成服务。具体服务主体、处理地点、保存期限和隐私政策必须在发布前补充。

客户端当前没有以提供语音身份识别或声纹认证为目的处理语音。语音内容本身仍可能包含个人信息或其他敏感内容，用户应在使用前确认其具有必要授权。

### 5. 用户自行配置的模型、MCP 和插件

SecAgent 允许用户配置自定义模型供应商、MCP 服务、Agent Plugin 和其他连接器。根据用户的配置和实际调用情况，这些服务可能获得：

- 当前消息、会话历史、图片、模型输出和工具上下文；
- 用户在 MCP 工具参数中提供的姓名、学生 ID、积分、班级、文件内容或其他业务数据；
- 插件所需的工作区文件、插件配置或插件专属数据；
- 用户配置的网络请求地址、请求参数和认证信息。

插件可能声明网络访问、工具、Skill、规则、预览或设置等权限。用户启用插件即表示主动选择使用该插件功能，但不代表我们能够控制插件作者或外部 MCP 服务如何处理数据。用户应在安装或启用前查看插件说明、权限声明、作者信息及其隐私政策。

SecScore 等教育连接器可能处理学生姓名、学生 ID、班级、积分、加分原因、撤销记录和操作审计信息。此类数据的业务处理主体、保存期限和权限管理应由相应教育服务运营者或学校/机构管理者另行确定。

### 6. 更新、插件市场和本地连接

客户端可能访问 GitHub、SECTL 插件市场或其代理地址以：

- 检查客户端更新；
- 下载和校验客户端安装包；
- 获取插件目录、插件说明和插件安装包；
- 检查和更新已安装插件。

相关网络服务可能从网络协议中获得 IP 地址、请求时间、User-Agent、请求路径和错误信息。当前默认地址包括：

- `https://api.github.com`、`https://github.com`、`https://raw.githubusercontent.com`；
- `https://ghproxy.sectl.cn`；
- `[如有其他实际市场或代理地址，请补充]`。

客户端还可能在本机 `127.0.0.1` 上提供仅供本机伴生应用发现和安装插件使用的本地 HTTP 接口。该接口默认不用于向公网提供服务，但同一台设备上的其他程序可能尝试访问它。

### 7. 匿名诊断、崩溃与体验失败遥测

客户端设置中的“上传匿名诊断数据”是遥测总开关，默认开启；关闭后客户端不发送心跳、Sentry 错误/崩溃、Agent 执行失败、模型连接失败、工具失败或其他遥测请求。教育机构或受管部署可以在安装配置中将 `SECTL_TELEMETRY_DEFAULT_ENABLED=false` 作为默认值。

开启匿名诊断时，客户端向 SecAgent 官方 relay 上传应用版本、系统与架构、更新通道、事件类型、阶段、持续时间、重试次数、Provider/模型/工具/插件标识、HTTP 状态码、错误分类、脱敏错误消息/堆栈、最近最多 50 条仅含阶段和状态的 Breadcrumb，以及输入输出长度、工具参数/结果大小和附件数量/大小等诊断元数据。普通遥测不上传用户原始输入、完整模型输出、原始模型请求 body、工具参数/结果原文、附件、API Key、Token、Cookie、邮箱或完整本地路径。

用户可以在每次上传前单独选择一个会话并确认上传一次完整诊断包。该诊断包包含所选会话消息和经过脱敏的运行 trace，不会因此持续开启完整会话采集；诊断包在 relay 对象存储中最多保留 7 天，每个安装每天最多 5 个。聚合事件最多保留 90 天，活跃实例心跳最多保留 30 天。

错误与崩溃信息由 `@sentry/electron` 处理，是否发送仍受上述总开关控制；Sentry 不接收完整对话内容。遥测请求在后台、短超时发送，失败不会阻塞客户端启动、对话或工具执行。

## 四、我们如何使用这些信息

我们仅在实现相应功能、响应用户操作、保障服务安全、维护应用稳定性、提供更新或履行法律义务所必要的范围内处理相关信息。根据具体场景，处理依据可能包括用户主动使用功能、履行服务关系、取得用户同意或法律法规允许的其他依据。

我们不会将用户自行配置的模型供应商、MCP 服务或插件产生的数据自动视为由官方服务统一管理。用户选择的外部服务可能按照自身规则将数据用于模型推理、日志、安全、计费、改进服务或其他用途，具体以该服务的规则为准。

## 六、境外处理和数据跨境

当前版本可能通过官方服务、语音服务、用户自行配置的模型或其他网络服务，将个人信息从中国大陆传输至境外服务器或由境外服务处理。境外处理可能带来当地法律保护程度不同、监管访问、网络攻击、供应商变更和跨境传输链路泄露等风险。

发布前必须针对每一个实际境外接收方补充以下信息：接收方名称和联系方式、所在国家或地区、处理目的和方式、个人信息种类、保存期限、用户权利行使方式、风险说明以及适用的数据跨境合规机制。未经核实，不得写成“已完成安全评估”“已完成标准合同备案”“已通过认证”或其他类似表述。

对于用户自行填写的境外模型、MCP 或插件地址，用户应在提交数据前自行确认其跨境处理安排，并避免提交不必要的个人信息、未成年人信息、敏感个人信息或受保密义务保护的信息。

## 七、保存期限和删除方式

### 1. 本地数据

除用户主动删除、卸载后清理或操作系统清理外，客户端当前没有统一的本地数据自动过期机制。会话、运行事件、审计记录、日志、插件数据、导出文件、配置文件和更新缓存可能持续保存在工作区中。

客户端中的“删除会话”目前只删除对应的会话目录及其会话文件，不等于删除：

- `audit/secagent.sqlite` 中的审计记录；
- `logs/` 中的应用和运行日志；
- `plugins/`、`.secagent-runtime/` 中的插件状态、配置或数据；
- `exports/` 中的导出文件；
- `.env`、`secagent.yaml` 或其他配置和备份文件。

如需尽可能完整地清理本地数据，应在退出客户端后删除用户实际配置的整个工作区；删除前应先备份需要保留的内容，并确认其中不再需要的令牌、API Key、会话和审计记录。客户端不会替用户删除第三方服务已经收到的数据。

退出 SECTL 官方账号会清空客户端当前保存的官方访问令牌、官方用户 ID 和官方账号邮箱字段，但不会自动删除已经产生的本地会话、日志、审计记录或第三方服务端数据。

### 2. 官方服务和第三方服务

官方服务、模型供应商、TTS 服务、MCP 服务、插件作者和 GitHub 等服务的保存期限由其实际运营主体确定。发布前必须逐项填写具体期限或确定方法，以及期限届满后的删除、匿名化或停止处理方式。当前客户端无法保证删除本地数据会同步删除这些服务端数据。

## 八、信息安全

我们会根据数据类型、处理规模和风险采取合理的访问控制、权限限制、传输保护、错误处理和安全运营措施。客户端对部分审计字段进行脱敏，但这不表示所有本地日志、会话内容、工具参数或插件数据都已匿名化或加密。

用户应：

- 使用安全的操作系统账户和设备锁屏；
- 妥善保护工作区、`.env` 文件、API Key 和访问令牌；
- 仅安装来源可信、权限与用途相符的插件；
- 在使用教育连接器或外部模型前完成机构内部授权和数据分类；
- 发现令牌泄露时立即退出登录、撤销令牌并联系相应服务方。

如发生可能影响个人信息权益的安全事件，我们将按照适用法律法规采取补救措施，并通过 `[通知渠道]` 或其他适当方式进行通知。

## 九、你的个人信息权利

在适用法律法规规定的范围内，你可以向我们提出以下请求：

- 查阅、复制、更正或补充个人信息；
- 删除个人信息、限制处理或撤回同意；
- 注销官方账号或询问账号相关处理情况；
- 要求解释本政策或特定处理活动；
- 对处理结果提出异议或投诉。

目前客户端没有统一的在线导出、远程删除或隐私请求管理入口。你可以通过以下方式提交请求：

> `[隐私联系邮箱]`

请在请求中说明请求事项，并根据需要提供能够验证身份和请求范围的必要信息。我们将在适用法律规定的期限内处理；如无法满足请求，将说明原因。对于由第三方模型、MCP、插件、学校/机构系统或其他外部服务独立处理的信息，你应直接向相应处理者提出请求。

你可以随时在系统设置中关闭语音唤醒、停止语音识别，或在操作系统设置中撤销麦克风权限。撤回同意不影响撤回前已经进行的处理，但可能导致相关功能无法继续使用。
